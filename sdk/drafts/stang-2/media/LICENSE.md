# Stang 2 LCD media declaration

The declared `ot-*.png` images are actual monochrome emulator LCD exports from
an isolated, private Stang 2 build. Credit: Octamod contributors. Capture plan,
source, image and emulator hashes are in `capture.json`. Firmware, raw memory,
LCD planes, cards and temporary native output are excluded.

LicenseRef-OT-UI-Documentation: these images are submitted for access/control
documentation and reviewer evaluation. Underlying Elektron interface elements
remain their owners' intellectual property. Original export does not relicense
third-party UI. Owner/reviewer rights verification is required before
publication; review is not automatic legal clearance. The separate SVG is an
original illustration under `presentation/LICENSE`, not UI evidence.
